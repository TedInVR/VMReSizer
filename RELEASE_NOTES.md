VM Re-Sizer 0.2.3

Step 1 is Adjust the stereo window, with a slider between large Push Back and Pull Forward buttons. The center retains the original disparity. Each button adjusts relative disparity by 0.2% of one eye frame width, within a range of -20% to +20%. Import resets the adjustment.

Step 2 is Frame your photo. Step 3 is Export. The stereo window shifts both eyes equally in opposite horizontal directions in the preview, individual-eye exports, and MyOwnReel side-by-side export. Exposed edges use the selected background color. Export retains the chosen canvas size and clips each eye independently.

Install through Help > Check for Updates, then quit to install.
